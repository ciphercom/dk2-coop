# Playing the co-op campaign

Shared Keeper co-op brings two people into one Dungeon Keeper 2 campaign. Each person has their own **Controller**: a local interface and camera for commanding the shared Keeper. Build rooms, manage creatures, spend the shared treasury and tackle the mission together.

## Start a session

Install the same DK2 Co-op package on both PCs and use matching game data, resource packs and gameplay-affecting settings. Launch `DKII-DX.exe`, choose **Multiplayer -> Co-op Campaign**, and connect through TCP/IP with distinct player names.

The host creates a session and selects an unlocked mission from DK2's campaign map. Accept the briefing to open the lobby. The other person joins that session; both confirm readiness and start. The host's campaign progress determines which missions are available, so the joining person can play along with a different unlock state.

The lobby holds two Controllers and keeps the chosen mission fixed while you ready up. To change missions, back out and create a new session.

## Share a dungeon

Both Controllers command the same Keeper's dungeon, creatures and resources. Each has separate hand contents within the shared native hand capacity. Move your camera independently to work in different parts of the dungeon.

One Controller can possess a creature at a time. Take turns by ending possession before the other Controller enters a creature. Let shared cutscenes finish, then continue the mission together.

## Continue the campaign

Mission completion updates the host's native campaign progress. Leave the result screen to return to the Co-op Campaign browser. The host creates another session and selects the next unlocked mission; the other Controller joins and both ready up again.

## Report a problem

Use [DK2 Co-op issues](https://github.com/ciphercom/dk2-coop/issues). Include the package filename or build identity from `flame/coop-build.json`, the mission and what each Controller was doing, together with the result you expected.
