DK2 CO-OP - SHARED KEEPER CAMPAIGN

Two people control one Keeper in the original Dungeon Keeper 2 campaign.
Build your dungeon together, share its creatures and resources, explore with
independent cameras and take turns possessing creatures.

INSTALL OR UPDATE
1. Each person needs Dungeon Keeper 2 v1.70 containing DKII-DX.exe.
2. Close DK2. Back up existing PATCH.dll, flame/ and Data/editor/.
3. Extract this ZIP beside DKII-DX.exe, accepting replacement.
4. Start DKII-DX.exe normally. Personal settings remain in flame/config.toml.

PLAY TOGETHER
Install the same package on both PCs and use matching original game data,
resource packs and gameplay-affecting settings. Both choose Multiplayer ->
Co-op Campaign and use the native TCP/IP connection flow with distinct names.
The host creates a session and chooses an unlocked mission through the native
campaign map. The other person joins; both confirm readiness and start.

Host progress determines available missions. The joining person can play along
with a different unlock state. Completion updates the host's campaign progress.
Return through the result screen and create/join a fresh session to choose the
next mission. To choose a different mission, create a new lobby.

Both Controllers command the shared dungeon, creatures and resources. Each has
separate hand contents within the shared native capacity and a local camera.
One Controller can possess a creature at a time. Take turns by ending possession
before the other Controller enters a creature. Let shared cutscenes finish, then
continue playing together.

PACKAGE AND SUPPORT
The build identity is in flame/coop-build.json. This package includes the Flame
runtime, editor patches by Quuz and the x86 D3DX libraries. The C++ runtime is
linked statically. The D3DX libraries come unmodified from Microsoft.DXSDK.D3DX
9.29.952.8 and are subject to flame/Microsoft-D3DX-LICENSE.txt.
